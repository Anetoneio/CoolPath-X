# Security Policy

## Reporting vulnerabilities

If you discover a security vulnerability in this repository, please **do not** disclose it publicly. Open a **private vulnerability report** via GitHub's security advisory feature (Settings → Security → "Report a vulnerability").

- The repository owner must enable private vulnerability reporting in the repository settings before reports can be submitted.
- Include a clear description of the issue, steps to reproduce, and any relevant proof‑of‑concept material.

## Scope

All source code, configuration files, CI pipelines, and documentation in this repository are in‑scope for security review.

## Disclaimer

This tool is **not validated for safety‑critical use**. It should not be deployed in environments where safety, health, or life‑critical outcomes depend on its correctness.
