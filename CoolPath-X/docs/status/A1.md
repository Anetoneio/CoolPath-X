## Blockers and Observations
- **Satellite Thermal Data Access:** ISRO Bhoonidhi and USGS EarthExplorer require user credentials and interactive authentication, which cannot be stored in the repo. Synthetic proxy grid with explicit `source: "proxy"` was generated and validated per project requirements.
- **Overpass Public Mirror Availability:**
  - `https://overpass-api.de/api/interpreter` experienced WinError 10060 connection timeouts from this environment.
  - `https://overpass.kumi.systems/api/interpreter` experienced read timeouts (>45-60s).
  - `https://overpass.osm.ch/api/interpreter` is Switzerland-only and returned 0 elements for India.
  - `https://overpass.openstreetmap.fr/api/interpreter` returned 403 Forbidden when default `OSMnx` or `Mozilla` user-agent / referer was used; resolved by setting custom `CoolPath/1.0` User-Agent and clearing `http_referer`. Successfully served all facilities and road network queries.
- **Drinking Water Sparsity in OSM:** Only about 2 mapped drinking-water points exist in OSM for this AOI (1 drinking water point, 1 water tap across 97 total facilities). Per strict project rules, no synthetic points were invented.
- **Shade Representation as Park Centroids:** "Shade" points in this dataset are predominantly park centroids (one single coordinate per park polygon). Consequently, mapped shade coverage appears denser than actual continuous shaded pedestrian walkway space; downstream routing and map display should not treat a park centroid as a precise, localized shaded shelter spot.
