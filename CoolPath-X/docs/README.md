# docs — ASTRA COOLPATH X documentation index

This folder holds the team's shared reference: the master plan, seat status files, per-seat task prompts, a resume template, and the decisions log.

## Entry points

- **Root `README.md`** — how to run the engine and web dashboard, folder ownership, contract-first rule.
- **Root `AGENTS.md`** — ownership map and where to start per seat (see its "Where to start" section).

## Contents

- `master-plan.md` — condensed project plan, mission, MVP, stretch, timeline, checkpoints (C0–C3), honesty rules.
- `HANDOFF.md` — Claude usage-limit handoff protocol, git workflow, ownership detail, large-file rule.
- `DECISIONS.md` — decisions log (orchestrator edits only).
- `prompts/RESUME.md` — template prompt for taking over a seat mid-task.
- `prompts/A1-data.md` — seat A1 task prompt (satellite and geo data).
- `prompts/A2-engine.md` — seat A2 task prompt (engine and API).
- `prompts/B1-dashboard.md` — seat B1 task prompt (dashboard).
- `prompts/B2-orchestrator.md` — seat B2 task prompt (orchestrator and worker view).
- `status/A1.md`, `status/A2.md`, `status/B1.md`, `status/B2.md` — per-seat status files.
