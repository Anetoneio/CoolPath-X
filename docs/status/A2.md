## Investigation Findings

### Problem 1: Multi-Crew Site Scheduling
- **Root Cause**: `scheduler.py` previously maintained a single `crew_cursor` time regardless of the `crews` parameter passed in the request. S01 (180 min work + 20 min rest = 200 min) advanced the single cursor from 07:00 to 10:20; S02 (120 min work + 15 min rest = 135 min) was dropped because `10:20 + 135 min = 12:35 > 12:00`.
- **Fix**: Replaced single cursor with a list of crew cursors (`[shift_start_min] * num_crews`). Each site in priority order is assigned to the earliest-available crew capable of completing the work and mandatory rest breaks before `shift_end_min`.
- **Contract Omission Rule**: `contracts/api.md` defines only `{"assignments": [...]}` with no schema field for omitted or unscheduled sites. Therefore, sites that cannot fit on any crew before shift end are omitted from `assignments`. With 2 crews and sites S01 + S02, both are scheduled.

### Problem 2: Heat Grid Coverage & Site Exposure
- **Heat Grid Extent**:
  - Longitude: `[72.5400, 72.6200]`
  - Latitude: `[22.9850, 23.0620]`
- **Site Containment Verification (Point-in-Polygon vs Bounding Box)**:
  Both the engine's `cell_for_point` ray-casting algorithm and an independent polygon bounding-box check yielded identical results for all 8 mock sites:

  | Site | Lat | Lon | `cell_for_point` | Bounding Box | Distance Outside Mock Grid |
  |---|---|---|---|---|---|
  | S01 | 23.0297 | 72.5571 | None (Fallback 50) | None | ~300 m west of cell C03 (lon 72.5600); south of C05 (lat 23.0320) |
  | S02 | 23.0462 | 72.5478 | Cell C09 | Cell C09 | Contained inside cell C09 |
  | S03 | 23.0339 | 72.5498 | None (Fallback 50) | None | ~20 m west of cell C05 (lon 72.5500) |
  | S04 | 22.9938 | 72.6213 | None (Fallback 50) | None | ~130 m east of cell C20 (lon 72.6200) |
  | S05 | 23.0151 | 72.5632 | Cell C01 | Cell C01 | Contained inside cell C01 |
  | S06 | 23.0384 | 72.5543 | Cell C05 | Cell C05 | Contained inside cell C05 |
  | S07 | 23.0685 | 72.6180 | None (Fallback 50) | None | ~720 m north of grid maximum lat (23.0620) |
  | S08 | 23.0574 | 72.6071 | None (Fallback 50) | None | ~1.7 km east of cell C18 (lon 72.5900) |

- **Code Verification**: The ray-casting implementation in `scoring.py` and coordinate passing order (`x=lon, y=lat`) are mathematically correct. The mock grid consists of 20 non-contiguous or stepped cells that leave 5 sites in gaps or outside the bounding area. Per instructions, mocks are left untouched; real data from A1 must provide complete spatial coverage.
- **Exposure Dependence on Shift Time**:
  - In `scoring.py`, temperature adjustment applies as `round(2.0 * max(0.0, forecast_temp - 25.0))`.
  - In Ahmedabad in November, cached forecast temperatures for 06:00 and 07:00 are ~18.7°C and ~18.5°C (both below 25°C baseline), producing 0 adjustment points.
  - Furthermore, sites outside the heat grid (like S01) immediately return the `MID_RANGE_EXPOSURE = 50` fallback. Thus, shifting start times between 06:00 and 07:00 on S01 yields 50 in both options.
