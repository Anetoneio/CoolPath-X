## Known Limitations & Blockers
- **All exposure scores are estimates**: Every score returned carries a plain-language reason string.
- **PLACEHOLDER constants**: Engine numeric constants (e.g. `SUMMARY_EXPOSURE_DIFF_PCT = 20`, confidence thresholds, scoring weights) are documented placeholders waiting on A1 verification.
- **policy.yaml thresholds**: `contracts/policy.yaml` intensity limits are `TODO_VERIFY` placeholders; scheduler uses conservative fallbacks flagged in assignment reasons pending A1 verification.
- **Python 3.14 environment**: Requires loosened `fastapi`/`httpx` pins (0.165.0/0.28.1) due to Python 3.14 standard library and anyio/httpx compatibility.

## Decisions and assumptions
- Python 3.14 environment required loosening fastapi/httpx pins (0.109.0/0.25.0 -> 0.165.0/0.28.1) due to httpcore/httpx 3.14 incompatibilities.
- networkx installed per task request (pure Python, no compiled deps). No hand-written Dijkstra fallback needed.
- data/processed/ does not yet exist (A1 domain); real mode gracefully falls back to mocks so endpoints never break.
- Exposure values are always labeled ESTIMATE per .clinerules rule 5; every score carries a plain-language reason string (per .clinerules rule 4).
- No hardcoded values that belong in contracts/policy.yaml; all such values read from the file with explicit TODO_VERIFY fallbacks documented.
