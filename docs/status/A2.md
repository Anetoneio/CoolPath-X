## What Is Complete
- **DATA_MODE Switching**: Full support for `DATA_MODE=mock` (reads `/mocks`) and `DATA_MODE=real` (reads `/data/processed/` with safe fallback to `/mocks` when unpopulated).
- **Core Endpoints**: All 7 endpoints implemented and contract-validated:
  - `GET /sites`: Catalogue of municipal work sites.
  - `GET /facilities`: GeoJSON Point features for verified water and shade facilities.
  - `GET /heat-grid`: GeoJSON Polygon features with LST, NDVI, cloud cover, and heat index.
  - `GET /confidence`: Composite confidence score (0–100) across 5 dimensions with provenance notes.
  - `POST /schedule`: Rule-based greedy scheduler with work/rest break compliance and plain-language reason strings.
  - `POST /route/compare`: NetworkX graph comparison between fastest route (R01) and lower-exposure alternative (R02) with water point proximity detection.
  - `POST /simulate`: Dynamic comparison of two schedule configurations with percentage difference summary.
- **Pre-Push Gate (`engine/verify.py`)**: Standalone verification gate running child processes in both data modes followed by the test suite.
- **Regression Suite (`engine/tests/test_regressions.py`)**: 7 regression tests covering synthetic 4-node routing, work/rest compliance, out-of-grid fallback, and simulation summary logic.
- **Engine Documentation (`engine/README.md`)**: Comprehensive documentation covering quick start, real request/response examples, scoring explanations, and verified limitations.
